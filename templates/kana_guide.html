How {{ sc.label|lower }} work

{{ sc.label }} is almost perfectly regular: each character is one sound, and a handful of marks and small characters change it. Learn these and you can read any {{ sc.label|lower }} word out loud.

The fastest way to get fluent at reading

  • Read words, not just single characters. After each lesson, the words course gives you real words using what you just learned.
  • Practise reading things you haven't seen. Read it shows you new words made only of {{ sc.label|lower }} you know.
  • Use hooks for the tricky ones. The memory hooks chart has a picture for every character.
